# Security policy

InterviewPrep is an educational repository. If you discover a vulnerability in
the repository or its automation, please report it privately through a GitHub
security advisory for [souradeepta/interviewprep](https://github.com/souradeepta/interviewprep/security/advisories).

Please do not publish exploit details in a public issue or pull request before
the maintainer has had an opportunity to investigate. Include the affected
file or workflow, reproduction steps, impact, and any suggested mitigation.

This project does not promise a response time. Avoid including credentials,
private data, or active exploit payloads in the report.
